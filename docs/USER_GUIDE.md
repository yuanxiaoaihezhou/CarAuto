# CarAuto 用户指南

## 快速入门

### 系统要求

- Python 3.8 或更高版本
- 现代浏览器（Chrome、Firefox、Edge 推荐）
- 摄像头（可选，用于驾驶员监控）
- 麦克风（可选，用于语音识别）

### 安装步骤

1. **安装 Python 依赖**

```bash
cd backend
pip install -r requirements.txt
```

2. **添加音乐文件**

将您的音乐文件复制到 `data/music/` 目录：

```bash
cp /path/to/your/music/*.mp3 data/music/
```

支持的格式：MP3, WAV, FLAC, M4A, OGG

3. **启动服务器**

```bash
python app.py
```

服务器将在 `http://localhost:5000` 启动

4. **打开浏览器**

访问 `http://localhost:5000`

## 功能详解

### 1. 主页

主页显示系统概览和快捷访问按钮。

**功能组件**：
- 天气信息卡片
- 正在播放卡片
- 快捷操作按钮

**使用方法**：
- 点击快捷按钮直接跳转到对应功能
- 查看当前播放的音乐信息
- 查看实时天气

### 2. 音乐播放器

完整的音乐播放功能。

**主要功能**：
- 播放控制（播放、暂停、停止、上一首、下一首）
- 音量调节
- 进度条
- 音乐库浏览
- 音乐搜索
- 显示封面和元数据

**使用方法**：

1. **扫描音乐库**
   - 点击"扫描"按钮
   - 系统自动识别 data/music/ 目录中的音乐文件

2. **播放音乐**
   - 在音乐库列表中点击歌曲
   - 或使用播放控制按钮

3. **控制播放**
   - ⏮️ 上一首
   - ▶️ 播放/⏸️ 暂停
   - ⏭️ 下一首
   - ⏹️ 停止

4. **调节音量**
   - 使用音量滑块
   - 或通过语音命令

5. **搜索音乐**
   - 在搜索框输入关键词
   - 实时过滤结果

### 3. 导航

地图导航功能（预留接口）。

**预设目的地**：
- 🏠 回家
- 🏢 去公司
- ⛽ 加油站
- 🅿️ 停车场

**扩展说明**：
可以集成高德地图、百度地图或 Google Maps API。

### 4. 电话

联系人和拨号功能。

**功能**：
- 联系人列表
- 拨号盘
- 呼叫按钮

**使用方法**：
- 点击联系人拨打
- 或使用拨号盘输入号码

### 5. 驾驶员监控

实时监测驾驶员状态。

**监测功能**：
- 👤 人脸检测
- 👁️ 眼睛状态（睁开/闭合/疲劳）
- 🙌 手势识别（竖大拇指/比V/手掌）
- 🎯 头部姿态（点头/摇头）
- 📊 注意力评分（0-100%）

**使用方法**：

1. **启动监控**
   - 点击"启动监控"按钮
   - 允许浏览器访问摄像头

2. **查看实时画面**
   - 摄像头画面显示在左侧
   - 检测结果显示在画面上方

3. **监控设置**
   - ✓ 疲劳驾驶警告
   - ✓ 手势控制
   - ☐ 隐私模式

**手势控制**：
- 👍 竖大拇指: 点赞/确认
- ✌️ 比V: 胜利手势
- 🖐️ 手掌: 停止/拒绝

**注意力评分**：
- 100%: 正常驾驶
- 50-99%: 轻度疲劳
- 0-49%: 危险状态

### 6. 设置

系统设置和个性化配置。

**设置分类**：

#### 显示设置
- 主题: 深色/浅色
- 亮度: 0-100%
- 方向: 横屏/竖屏
- 屏幕超时: 300 秒

#### 音频设置
- 音量: 0-100%
- 平衡: -100 (左) 到 100 (右)
- 低音: -10 到 10
- 高音: -10 到 10
- 均衡器预设: 正常/摇滚/流行/爵士/古典

#### 语音设置
- 启用语音识别: 开/关
- 语言: 中文/English
- 唤醒词: "你好汽车"
- 语音反馈: 开/关

#### 驾驶员监控设置
- 启用监控: 开/关
- 疲劳警告: 开/关
- 手势控制: 开/关
- 隐私模式: 开/关

#### 系统设置
- 系统语言: 中文/English
- 单位: 公制/英制
- 时间格式: 24小时/12小时
- 日期格式: YYYY-MM-DD

**使用方法**：
- 调整设置后自动保存
- 点击"刷新设置"重新加载
- 点击"恢复默认"重置所有设置

## 故障排除

### 音乐无法播放

**问题**: 点击播放没有反应

**解决方案**：
1. 确认音乐文件在 data/music/ 目录
2. 点击"扫描"按钮刷新音乐库
3. 检查文件格式是否支持
4. 查看浏览器控制台错误信息

### 摄像头无法访问

**问题**: 驾驶员监控显示黑屏

**解决方案**：
1. 检查浏览器权限设置
2. 确认没有其他应用占用摄像头
3. 尝试在设置中更改摄像头索引
4. 检查摄像头硬件连接

### 麦克风无法识别

**问题**: 语音识别无响应

**解决方案**：
1. 检查浏览器麦克风权限
2. 测试麦克风是否正常工作
3. 检查网络连接（使用在线语音识别）
4. 尝试重启语音识别

### 页面加载缓慢

**问题**: 界面响应慢

**解决方案**：
1. 清除浏览器缓存
2. 关闭其他标签页
3. 检查服务器日志
4. 重启应用服务器

## 性能优化建议

### 音乐库优化
- 建议音乐文件数量不超过 1000 首
- 使用合适的比特率（128-320 kbps）
- 定期清理不需要的文件

### 监控性能
- 降低视频帧率（设置中调整）
- 使用较低的检测置信度阈值
- 在不使用时关闭监控

### 系统资源
- 关闭不使用的功能
- 定期重启应用
- 监控 CPU 和内存使用

## 隐私和安全

### 数据保护
- ✓ 所有数据本地存储

## 高级功能

### 自定义主题

编辑 `frontend/static/css/style.css` 自定义颜色：

```css
:root {
    --primary-color: #2196F3;  /* 主色调 */
    --bg-dark: #121212;        /* 背景色 */
    --text-primary: #FFFFFF;   /* 文字色 */
}
```

### 添加自定义语音命令

编辑 `backend/app/voice_recognizer.py`：

```python
COMMANDS = {
    '你的命令': 'command_name',
    # ... 其他命令
}
```

### 集成地图 API

在 `backend/app/config.py` 中添加 API 密钥：

```python
MAP_API_KEY = 'your_api_key_here'
MAP_API_PROVIDER = 'amap'  # or 'baidu', 'google'
```
